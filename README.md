# 🖼️ Image Slider using HTML, CSS & JavaScript

This is a **simple and elegant Image Slider** built using **HTML, CSS, and JavaScript**.  
It allows users to slide through **multiple images** using navigation arrows.  
The slider is smooth, easy to use, and perfect for beginners learning **basic DOM manipulation** in JavaScript.  

---

## 📸 Screenshot

![Image Slider Preview](images/Screen-shot.jpeg)

---

## 🚀 Features
- ▶️ **Manual image sliding** using navigation arrows  
- ⬅️➡️ **Previous / Next buttons** to navigate between images  
- 🎨 **Smooth transition effects** with CSS  
- 🧩 Supports **5 images**  
- 🧼 **Simple and clean design** — easy to customize  
- ⚠️ **Not responsive** (desktop view only)

---

## 🛠️ Technologies Used
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**

---

## 📂 Project Structure
```bash
├── index.html          # Main HTML file
├── style.css           # Styling for the slider
├── script.js           # JavaScript for slide control
├── Screen-shot.jpeg    # Project screenshot
└── images/             # Folder containing 5 images
```

## 🔧 How to Use
1. Clone this repository:
   ```bash
   git clone https://github.com/Farah-Saleem270/imageSlider
   ```
2. Open the project folder:
   ```bash
   cd imageSlider
   ```
3. Run index.html in your browser.
4. Click the left/right arrows to slide between images 🎞️
